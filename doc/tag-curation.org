#+TITLE: SF-history reading list — tag curation sidecar
#+STARTUP: content
#+OPTIONS: ^:{}

Sidecar for the_barbarians SF-history reading list. Holds the controlled
tag vocabulary, the LLM map-maintenance prompt, and the rewrite map. The
ORL package stays vocabulary-agnostic and stores each entry's full, raw
subject set in its =:SUBJECTS:= property; the package projects that set to
the headline tags via the rewrite map.  This sidecar is the per-list
curation layer that decides those raw -> vocabulary mappings.

* Controlled vocabulary (narrative threads)
Copy this line into the reading-list preamble (gives Org C-c C-c
completion; not ORL-specific):

#+begin_example
,#+TAGS: gold_rush vigilance crime fires waterfront mining women labor politics culture urbanism environment printing pictorial primary_source reference biography
#+end_example

Glosses:
- gold_rush      :: Gold Rush era, diggings, the 1848–55 boomtown
- vigilance      :: vigilance committees, extralegal order
- crime          :: arson, the Hounds, the coroner's office, lawlessness
- fires          :: the recurring conflagrations
- waterfront     :: port, harbor, ships, shoreline
- mining         :: mining industry, machinery, the mineral hinterland
- women          :: women's history, female proprietors
- labor          :: work, labor movements, the working class
- politics       :: government, public sphere, social movements
- culture        :: cultural/social construction, everyday life, race
- urbanism       :: city-building, planning, architecture
- environment    :: resource/environmental history
- printing       :: the book and printing trade
- pictorial      :: (form) photographic/visual books
- primary_source :: (form) letters, diaries, documents
- reference      :: (form) chronologies, encyclopedic reference
- biography      :: (form) biographical treatment

* Map-maintenance prompt (paste with the reading-list file)
#+begin_src text
You are maintaining the controlled-vocabulary rewrite MAP for an Org-mode
reading list. You do NOT edit the file: the org-reading-list package applies
the map deterministically — it projects each heading's :SUBJECTS: property to
the headline :tags:. Your job is to (a) extend the map to cover subject tokens
it does not yet handle, and (b) infer threads for entries the map leaves thin.

Each book is a heading under "* Books". Its raw subjects are in the :SUBJECTS:
property: a ";"-separated list of normalized tokens (the full, uncapped set
harvested from the catalog sources). The headline :tags: are the package's
OUTPUT — already projected through the map below — so ignore them as input.
Read :SUBJECTS: (and :TITLE:/:ABSTRACT: for inference).

Controlled vocabulary — the ONLY tags the map may target (the #+TAGS: line and
glosses in this sidecar are authoritative; do not invent tags outside it):
gold_rush vigilance crime fires waterfront mining women labor politics culture
urbanism environment printing pictorial primary_source reference biography

Tasks:
1. MAP ADDITIONS. Across all entries, collect every :SUBJECTS: token the current
   map below does not already handle (it is neither a mapped key nor listed
   under DROP). For each, decide either the nearest vocabulary thread (collapse
   synonyms, variants, and MARC subdivisions) or DROP (universal /
   non-discriminating tokens such as history, san_francisco*, california*, or
   anything with no home in the vocabulary). Never target a tag outside the
   controlled vocabulary. Output the decisions as new map lines in the same
   "thread <= raw, raw, ..." / "DROP <= raw, ..." form, ready to merge.
   (Tip: M-x org-reading-list-preen-tags with a prefix arg (or the dispatch
   menu's whole-buffer toggle) previews each entry's unresolved tokens before
   applying.)
2. THIN-ENTRY INFERENCE. For any entry whose :SUBJECTS:, after the full map
   (current + your additions), yields fewer than 2 vocabulary threads, infer the
   2-4 threads the book is about from its :TITLE: and :ABSTRACT:. Output a table:
   citekey | mapped threads | inferred threads, marking "(REVIEW)".
3. Do NOT output rewritten headline tags or edit any property: the package
   re-derives the tags from :SUBJECTS: through the map once it is updated (M-x
   org-reading-list-preen-tags). Propose map and inference changes only; I apply
   them after confirming.
